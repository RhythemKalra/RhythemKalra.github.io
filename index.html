01 class project · applied AI

Multi-agent resume matcher

Four AI agents that read a resume and a job description, score the match, reason about why it falls short, and rewrite the resume, looping until a critic is satisfied. The part I'm proudest of: it's not allowed to invent skills you don't have. That rule is enforced in code, not just hoped for.

  • Parser
  • Scorer
  • Critic
  • Rewriter
  • Python
  • scikit-learn
  • k-means
  • logistic regression
  • rule engine
  • live streaming UI
02 side project · AI

An AI video editor

A Claude Code workspace that edits talking-head videos for me. It transcribes the footage, cuts silences and retakes, adds motion graphics, and exports both an MP4 and an editable timeline for Final Cut or DaVinci Resolve.

  • FFmpeg
