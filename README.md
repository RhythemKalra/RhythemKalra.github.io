# rhythemkalra.github.io

My personal portfolio: who I am, what I've built, and what I keep thinking about.

**Live site:** https://rhythemkalra.github.io

## Built with

- Plain HTML, CSS and JavaScript. No frameworks, no website builders.
- Hosted free on GitHub Pages.

## What's in here

| File | What it does |
| --- | --- |
| `index.html` | All the content and the page structure |
| `style.css` | The look: colours, fonts, layout, the phone version |
| `script.js` | The interactive bits: ink/paper theme toggle, "make it dance" mode (or press D), experience tabs, project filters, draggable skill stickers, flip cards, tilting cards, counting numbers, scroll progress bar and copy-email sparkles |

## Design idea

Two moods for one person. **Ink** is the dark, glowing side: late nights, AI, building things.
**Paper** is the notebook side: thinking things through, writing in the margins. The toggle in
the corner switches between them. The grid background, the index card and the handwritten
margin notes are all meant to make it feel like a notebook I'm still writing in.
